설치

    
App Store 에서 Scriptable 을 먼저 받아 두세요. 무료입니다.

    

      
1
코드 복사를 누르고 Scriptable 을 열어 우측 상단 + 로 새 스크립트를 만든 뒤 붙여넣습니다. 이름은 아무렇게나 지어도 됩니다.

      
2
홈 화면 빈 곳을 길게 눌러 위젯 추가 → Scriptable → 중간 크기를 놓습니다.

      
3
놓인 위젯을 길게 눌러 위젯 편집 → Script 를 방금 만든 스크립트로 지정합니다. When Interacting 은 Run Script 로 두세요.

    

  


  

    

      갱신
      iOS 가 갱신 시점을 정합니다. 위젯은 깨어날 때마다 네이버를 새로 조회하지만 실제 주기는 보통 15분~1시간입니다. 위젯을 탭하면 즉시 최신값으로 다시 그립니다.
    

    

      그래프
      설치한 순간부터 쌓입니다. 네이버가 과거 시세를 주지 않아 소급 채우기가 불가능합니다. 첫날은 안내 문구가 보이고, 값이 두 개 이상 모이면 선이 그려집니다.
    

    

      주의
      개인용 저빈도 조회를 전제로 만들었습니다. 위젯은 같은 일정을 2분 안에 다시 조회하지 않도록 스스로 제한합니다. 일정이 매진되거나 편명이 바뀌면 위젯이 마지막으로 받은 값을 갱신 실패 표시와 함께 보여줍니다.
